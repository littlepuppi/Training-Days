# Training Days

A JavaScript script about random athletic events and training time. `getRandEvent` randomly returns Marathon, Triathlon, or Pentathlon; `getTrainingDays` is meant to return a number of training days for that event; `logEvent` and `logTime` print a message for an athlete named Nala.

Comments in the file are about variable scope. As written, `days` is declared with `let` inside the `if` branches, so those inner values are not returned by `getTrainingDays`.

## Getting started

```bash
node main.js
```

Practices: scope, conditionals, and functions.
